# Feature de Mix — Spotify

Présentation HTML d'une fonctionnalité Spotify, réalisée dans le cadre de l'EFREI : plan de réalisation, stratégie test & learn, mesure de l'adoption, RGPD et accord de traitement des données, équilibre économique, passage à l'échelle, grille valeur / faisabilité / ROI.

**Présentation en ligne : https://mvtteo.github.io/spotify_pres/** · version PDF : `Feature_de_Mix.pdf`

## Lancer en local

Ouvrir `Feature_de_Mix.html` dans un navigateur, ou servir le dossier avec le `Dockerfile` (nginx) fourni.
